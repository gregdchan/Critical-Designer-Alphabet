## Getting Started

### What is this platform?

The Critical Designer Alphabet is a collaborative design thinking platform that helps teams explore strategy and innovation through a **pluriversal lens**. It combines:

- 📚 **Educational cards** introducing critical design concepts
- 💬 **Real-time collaboration** with chat, voting, and shared timelines
- 🏆 **Gamification** rewarding quality participation
- 📊 **Advanced analytics** tracking engagement and equity
- 🤖 **Optional AI** for intelligent recommendations

### Joining a Session

1. Receive a **session code** from your facilitator (e.g., `ABC123`)
2. Navigate to the join page: `/join?code=ABC123`
3. Enter your name and email (optional)
4. Choose your display color
5. Click "Join Session"

## For Participants

### Contributing Ideas

1. **View Active Questions**: Questions appear in the main session view
2. **Select Relevant Cards** (recommended):
   - Click the 🎴 "Cards" button to browse
   - Search by keyword or filter by category
   - Select up to 5 cards that relate to your response
   - Recommended cards are highlighted with ⭐
3. **Write Your Response**:
   - Minimum 10 characters
   - Aim for 200+ characters for "Deep Thinker" badge
   - Reference your selected cards in your text
4. **Submit**: Your contribution appears immediately for all participants

### Voting

- 👍 **Upvote** ideas that resonate with you
- Votes are visible to everyone (unless you enable anonymous voting)
- Each vote earns the contributor 1 point
- You can vote on as many responses as you like

### Using the Timeline

Add items to the shared roadmap:

1. Click **"Add to Timeline"**
2. Select **Now** (immediate), **Next** (near-term), or **Later** (long-term)
3. Add optional owner, metric, or risk note
4. Categorize the timeline visually on the Roadmap chart

### Real-Time Chat

- Click the **Chat** tab to discuss ideas
- Supports markdown formatting
- Messages sync instantly across all participants

### Checking Your Progress

- View the **Leaderboard** (🏆 button) to see your rank
- Check **Analytics** tab to see your personal card journey
- Review earned badges in your participant profile

## For Facilitators

### Setting Up a Session

1. Create a session from the dashboard
2. Configure questions with recommended cards
3. Set session status: **Planned** → **Live** → **Done**
4. Share the session code with participants

### Managing Phases

Phases help structure your workshop:

```
Example: Innovation Workshop
├─ Phase 1: Problem Discovery (30 min)
├─ Phase 2: Ideation (45 min)
├─ Phase 3: Prioritization (20 min)
└─ Phase 4: Action Planning (25 min)
```

**Features**:
- Countdown timer visible to all
- Auto-advance or manual control
- Lock responses when phase ends

### Awarding Recognition

Use the **🏆 Award Recognition** button to grant special badges:

| Award | Points | When to Use |
|-------|--------|-------------|
| ✨ Most Inspiring | 50 | Sparked creative thinking |
| ❓ Best Question Asker | 40 | Asked thought-provoking questions |
| 🤝 Ultimate Team Player | 45 | Supported teammates |
| 🚀 Innovation Champion | 55 | Pushed boundaries |
| 🌉 Bridge Builder | 45 | Connected perspectives |

### Monitoring Participation

**Equity Dashboard**:
- Navigate to **Analytics** → **Participation Equity Chart**
- Check the **Equity Score** (0-100%)
- 80%+: Excellent balance ✅
- 60-79%: Good, minor adjustments 🟡
- <60%: Facilitate quieter voices ⚠️

**Real-Time Pulse**:
- Shows responses per minute over last 30 minutes
- Auto-refreshes every 10 seconds
- Helps identify energy dips

### Exporting Data

**Participant Data**:
- Navigate to Privacy & Data settings
- Export as JSON (structured) or CSV (spreadsheet)

**Session Reports**:
- Use the **Download** button to export visualizations
- Screenshots can capture full analytics dashboards

## Card System

### Card Categories

The Critical Designer Alphabet includes cards across themes:

1. **Pluriversality** - Multiple worlds, perspectives
2. **Decolonization** - Challenging dominant narratives
3. **Design Justice** - Equity and inclusion
4. **Speculation** - Imagining futures
5. **Reflection** - Critical self-awareness

### How Cards Work

**Selection**:
- Max 5 cards per response
- Cards accumulate in your profile
- Unlock advanced cards by participating

**Recommendations**:
- Questions can suggest specific cards (⭐ highlighted)
- AI can recommend based on response text (if enabled)

**Validation**:
- Some questions require minimum card count
- Validates that you reference cards meaningfully

### Progressive Unlocking

Earn access to advanced cards:

| Tier | Requirement | Cards Unlocked |
|------|-------------|----------------|
| 1 | Join session | Starter pack (8 cards) |
| 2 | 50 points | Intermediate concepts |
| 3 | 100 points | Advanced theory |
| 4 | Quality badges | Expert-level cards |
| 5 | 150 pts + expertise | Specialized concepts |
| 6 | 200 pts + 10 responses | Full collection |

## Gamification & Badges

### Point System

**Base Points**:
- Join session: +5
- Each response: +2
- Each vote received: +1
- Badge bonuses: +10 to +75

**Quality Multiplier**:
```
Quality Score = Votes × (1 + CardDiversity × 0.1)
```

Example: 10 votes + 5 unique cards = 10 × 1.5 = **15 quality points**

### Badge Categories

#### 🌱 Participation Badges
- **First Steps** (10 pts): First contribution
- **Prolific Contributor** (25 pts): 5+ ideas
- **Early Bird** (15 pts): First 3 to contribute

#### 🎴 Card Badges
- **Card Curious** (15 pts): Use 5 different cards
- **Card Scholar** (30 pts): Reference 10 cards total
- **Card Expert** (50 pts): Master 10+ unique cards with 5+ responses
- **Pluriverse Champion** (75 pts): Use 15+ unique cards
- **Theory-Practice Bridge** (25 pts): Combine 2+ cards in one response

#### 💎 Quality Badges
- **Thoughtful Contributor** (50 pts): Average 3+ votes per response
- **Deep Thinker** (40 pts): 5+ responses with 200+ characters
- **Gem Finder** (35 pts): Identify high-quality contributions

#### 🤝 Community Badges
- **Community Champion** (20 pts): Vote on 10+ ideas
- **Engagement Champion** (35 pts): Receive 10+ votes total
- **Collaboration Catalyst** (30 pts): Build on others' ideas

#### 🏅 Facilitator Awards
- Granted manually by facilitators
- 40-55 points each
- Visible recognition in leaderboard

## Privacy & Data

### Privacy Settings

Access via **🔒 Privacy & Data** button:

**Anonymous Voting**:
- Your votes won't be attributed to your name
- Facilitators see aggregates, not individual votes

**Hide My Name**:
- Display as "Anonymous Participant" in leaderboards

**Disable Activity Tracking**:
- No "last active" timestamps shown

**Opt Out of Leaderboard**:
- Your ranking won't appear publicly

### Data Export

**JSON Export**:
```json
{
  "session": { "code": "ABC123" },
  "participant": { "name": "...", "points": 125 },
  "responses": [...],
  "timeline": [...]
}
```

**CSV Export**:
| Response ID | Text | Cards | Votes | Created At |
|-------------|------|-------|-------|------------|
| abc-123 | ... | Card A; Card B | 5 | 2025-01-15 |

### Data Deletion

**GDPR Compliance**:
1. Request deletion via Privacy settings
2. Confirmation dialog with warning
3. 30-day processing period
4. Permanent removal from all systems

## AI Features (Optional)

### Enabling AI

1. Navigate to **🤖 AI Settings**
2. Toggle "Enable AI Recommendations"
3. Enter your OpenAI API key (from [platform.openai.com](https://platform.openai.com/api-keys))
4. Select model: GPT-4 (best), GPT-4 Turbo (fast), GPT-3.5 (budget)
5. Adjust creativity slider (0.0 = focused, 1.0 = creative)
6. Save settings

### Smart Card Recommendations

When typing a response:
1. AI analyzes your text + question context
2. Suggests 3-5 relevant cards
3. Shows relevance score (0-100%)
4. Provides reasoning for each suggestion
5. Click to add card to your selection

**Relevance Scores**:
- 80-100%: Highly Relevant (green)
- 60-79%: Relevant (blue)
- 40-59%: Somewhat Relevant (yellow)
- <40%: May Be Relevant (gray)

### Response Quality Analysis

After submitting:
1. AI analyzes depth and card integration
2. Provides quality score (0-100)
3. Gives constructive feedback
4. Suggests 2-3 improvements

**Note**: This feature is optional and fully under your control.

### Privacy Notice

When AI is enabled:
- Your response text is sent to OpenAI for analysis
- No personal data (name, email) is included
- OpenAI does not use API data to train models
- You control when AI is active
- See [OpenAI's Data Usage Policy](https://openai.com/policies/api-data-usage-policies)

## Troubleshooting

### Session Issues

**Can't join session**:
- Verify session code is correct (case-sensitive)
- Check that session status is "Live" (not "Planned" or "Done")
- Ensure you have internet connection
- Try refreshing the page

**Lost connection**:
- Real-time updates use WebSocket
- Check browser console for errors
- Try leaving and rejoining session
- Contact facilitator if issue persists

### Card Issues

**Cards not loading**:
- Clear browser cache and reload
- Check if Sanity CMS is accessible
- Verify internet connection
- Try incognito/private browsing mode

**Can't select card**:
- Check if you've reached max (5 cards)
- Verify card isn't already selected
- Ensure card panel is fully loaded

### Performance Issues

**Slow visualization rendering**:
- Large datasets may take 3-5 seconds
- Try reducing time window (for Real-Time Pulse)
- Close other browser tabs
- Use Chrome/Edge for best D3.js performance

**High memory usage**:
- Analytics page loads all data
- Consider exporting and analyzing externally
- Clear localStorage: `localStorage.clear()`

### AI Issues

**AI not responding**:
- Verify API key is valid
- Check OpenAI account has credits
- Test API key at [platform.openai.com](https://platform.openai.com)
- Try different model (GPT-3.5 as fallback)

**Poor recommendations**:
- Increase creativity (temperature) for more diverse suggestions
- Provide more context in your response
- Try GPT-4 instead of GPT-3.5

### Data Issues

**Export not working**:
- Check browser allows downloads
- Try different format (JSON vs CSV)
- Ensure sufficient storage space
- Disable popup blockers

**Lost progress**:
- Data stored in localStorage (browser-specific)
- Switching browsers loses local data
- Use same browser throughout session
- Export data regularly as backup
