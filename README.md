# Critical Designer Alphabet

Critical Designer Alphabet is a collaborative workshop platform with:

- `designeralphabet/`: SvelteKit app for facilitator, participant, session, presentation, and export views
- `content/`: Sanity Studio for workshop templates, cards, and themes
- `docs/`: canonical project documentation

## Local Development

```bash
./run-all.sh
```

Or run each app manually:

```bash
cd designeralphabet && npm install && npm run dev
cd content && npm install && npm run dev
```
